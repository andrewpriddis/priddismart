# PriddiSmart Static Website

This folder is a ready-to-upload static site (works on GitHub Pages).

## Pages
- index.html
- services.html
- smart-coolers.html
- contact.html

## Customize
- Colors and typography: `assets/css/styles.css`
- Navigation behavior: `assets/js/main.js`
- Logo: `assets/img/logo.svg`

## Deploy on GitHub Pages
1. Put these files in the root of your GitHub repo (same level as `index.html`).
2. In GitHub: Settings → Pages → Build and deployment
   - Source: Deploy from a branch
   - Branch: `main` / `(root)`

## Notes on images
Images are included in `assets/img/`. If you want to replace them, keep the same filenames or update the `<img>` paths.
